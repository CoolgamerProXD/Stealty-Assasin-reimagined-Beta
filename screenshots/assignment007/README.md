# Assignment 007 full-resolution visual review

These are genuine 1280×720 Godot campaign captures from regression run [45142836911](https://github.com/CoolgamerProXD/Stealty-Assasin-reimagined-Beta/actions/runs/45142836911), reconstructed from that run's per-image GitHub check annotations. Each JPEG was verified to decode fully at 1280×720. The matching lossless PNG originals remain in the `assignment006-visual-acceptance` Actions artifact for that run; this folder contains native-resolution review JPEGs, not those lossless source files.

Run `45142836911` is a **before-fix review set**, captured before the latest changes to character staging, Meridian's restaurant portal/lighting, and Tung Chung lighting. Inspection found characters frozen mid-stride in multiple views, a pinched/visually occluding restaurant entrance, and an underexposed Tung Chung station. The scenes are still visibly prototype/blockout quality, and this review does not provide artistic, cultural, or playtest sign-off. Keep this set as a record of identified defects; inspect the subsequent run's images before judging the changes.
