## Automated

With Godot 4.4.1 installed, from the repository root:

```sh
godot --path . --import
godot --headless --path . --script res://tests/run_tests.gd
godot --headless --path . --script res://tests/npc_route_soak_test.gd
```

Run the import with a working graphics display/driver: Godot 4.4.1 can emit spurious null-texture errors when its dummy renderer generates GLB previews. CI uses Xvfb and Mesa for import. The first command imports resources and registers global script classes. The second must exit 0 and print the check/failure totals. It exercises access, inventory, objective uniqueness and extraction, memory expiry, versioned/corrupt saves and backup recovery, snapshot restoration, FOV decisions, NPC reaction/recovery, disguise permissions, physics input, navigation detours, actual ray occlusion and the world's interaction path. The separate route-cycle test uses accelerated physics to exercise both endpoints of four Meridian wing/suite routes and all 16 station routes; it does not prove general obstacle avoidance or human playability. It is not a substitute for an interactive graphics/navigation playtest. Save tests use uniquely named `user://assassin_test_*.json` files and remove them and their `.bak`/`.tmp` files; they do not touch the playable save.
